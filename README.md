# CPA Quota for Android

A native Kotlin and Jetpack Compose client for inspecting CPA quota and CAP usage, chatting with available models, and using the independent monitoring service. The goal is to preserve the iOS product's behavior within Android's platform limits. This repository is still in planning; it does not ship an Android app yet.

## Selected implementation plan

Use the [native Android plan in PR #9](https://github.com/rinmashiro0529/cpa-quota-Android/pull/9). Its [plan index at the selected revision](https://github.com/rinmashiro0529/cpa-quota-Android/blob/c4369a75945d1d21f4764d177cb9a5532d36f629/proposals/2026-11-25-native-android-independent/README.md) links the source baseline, feature matrix, delivery tasks and verification requirements. The original planning documents and their issue queue are no longer the implementation baseline.

Read [AGENTS.md](AGENTS.md) before contributing. Selecting the plan does not mean its implementation or device checks have passed.
